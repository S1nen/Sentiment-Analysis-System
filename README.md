## Sentiment Analysis System

-This project is about analysing user reviews from amazon and it predicts whether a review  is positive or negative.

#### Features in the dataset-
-The dataset contains 5 colummns and 3150 rows.
rating - this column contains the user ratings , like 5 or 4 or 3.
date - this column contains in which date the user posted the review.
variation - this column contains from which variation of the amazon alexa system, the review was recorded.
verified reviews - column contains the reviews posted by the user 
feedback - contains binary value which says if the value is postive or negative.
